动画与过渡

页面过渡

  • 主界面→运行界面: 缩放淡入 (0.92→1.0 Scale + 0→1 Fade, 350ms easeOutCubic)
  • 运行界面→主界面: 反向缩放淡出, 动画完成后自动恢复竖屏（无硬编码延迟）
  • Hero 共享元素: 预览组件通过 Hero(tag: 'run_preview') 在页面间平滑位置过渡
  • 面板滑入: 320ms easeOutCubic (右侧滑入, translateX: 100% → 0)
  • 面板滑出: 等待 350ms 确保面板完全退出后再触发返回动作
  • 运行按钮阴影: box-shadow 常驻 0 5px 12px rgba(16,16,16,0.28)

效果动画

  • 闪烁效果: 2s linear infinite, 7色彩虹循环 (白→红→黄→绿→蓝→紫→青→白)
  • 闪烁附带: text-shadow 同色发光效果
  • 抖动效果: 500ms ease-in-out infinite alternate, 3层分离
  • 抖动层1: 粉色描边 6px, 随机位移 (-5~5px)
  • 抖动层2: 青色描边 3px, 随机位移 (-5~5px)
  • 抖动层3: 纯色前景, 随机位移 (-5~5px)
  • 滚动文字: requestAnimationFrame 驱动, 线性无限循环
  • 滚动速度: 基础 60 px/s × 速度倍率 (0.5~5.0)
  • 滚动循环: loopWidth = boxWidth + textWidth + 50px gap
  • 生命周期感知: App 切后台时停止动画循环，恢复前台后从断点续播

滚动原理 (原型 JS 实现)

布局结构

  • 容器: absolute + flex, white-space: nowrap
  • 内容: flex-row [Spacer(boxWidth), Text, Gap(50px)]
  • 循环宽度: boxWidth + textWidth + 50
  • 字体大小: boxHeight * size比例
  • boxHeight = boxWidth / (21/9)

动画逻辑

  • 驱动: requestAnimationFrame 递归循环
  • 偏移: -(elapsedSeconds * velocity) % loopWidth
  • 应用: CSS transform: translateX(dx)
  • 基础速度: 60 px/s × 速度倍率 (0.5~5.0)
  • GAP: 50px (文字后空白间距)
  • 不足 0 时: 50ms 延迟重试 (等 layout)
